Methodology and import details

Medium anchor: 0.00015 Wh/input token, 0.0006 Wh/output token; cache reads weighted 0.1. Small models use 0.25x, frontier models 3x. Carbon: 480 g CO2e/kWh. On-site cooling: 1.1 L/kWh.

Unknown models have no price estimate; footprint uses a disclosed generic medium factor. Missing counts are excluded, never inferred from text. Training, hardware, local device use and electricity-generation water are excluded. Claude cache writes use the five-minute rate unless a one-hour subdivision is reported (2x base input); context premiums, discounts and extra service fees are excluded.

Sources: Anthropic and OpenAI official API pricing; CarbonBit methodology v1.1.0 (Epoch AI 2025, Google 2025 and Ember 2024). Full source URLs and limitations: docs/usage-methodology.md in the application repository.
