      Dashboard guide

      Hide Overview for more room. Drag the divider between sessions and the stream, or focus it and use the arrow keys. Double-click it to restore the default width. These layout choices are saved on this device.

      Needs you lists approvals before replies. Select a request to inspect it without sending anything to the agent. When nothing needs you, this space shows working sessions instead.

      Project signal groups recorded events into one-minute bars on a common scale. A gold bar includes a logged wait, not necessarily a pending request. Select a lane to filter by project; select it again to show all projects. Empty minutes mean no recorded events, not inactivity.

      Select a session to inspect its latest action, or select a stream event to read that specific record alongside the current session. Back to stream or Esc returns you to the list. Indented sessions are sub-agents.

      Timelines share the same 30-minute window. Marks are recent recorded events; blank space is not a measure of idle time. The scanner reads a bounded part of each log.

      Filters apply to sessions and the stream. Live now includes active sessions and idle sessions seen in the last 15 minutes. Active sessions stay visible in every time window.

      Review permissions and reply in the original app. File-only sources report changes, not tool calls or token usage.
